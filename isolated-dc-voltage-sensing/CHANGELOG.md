# Changelog

All notable changes to this project will be documented here.

---

## [v1.0] — May 2026

### Added
- Initial release
- Eagle CAD schematic and board layout for isolated DC voltage sensing
- AMC1200-based galvanic isolation with 0–300V input range
- MCP6002 output signal conditioning stage
- Dual isolated power supply (LD1117 + L7805)
- Anti-aliasing RC filter at ADC input (150Ω + 1nF)
- Gerber files for PCB fabrication
- Bill of Materials (BOM)
- Practical hardware implementation and validation
